GoodbyeDPI for Firefox

처음 한 번만 준비하기

확장 프로그램은 스스로 프로그램을 실행할 수 없어, 내장된 도우미를 한 번 설치해야 합니다. 인터넷에서 따로 받을 파일은 없습니다.

  1. 사생활 보호 창 실행 허용

    Firefox 는 프록시 설정을 바꾸는 확장에 이 권한을 요구합니다. 주소창에 about:addons 를 입력하고 GoodbyeDPI for Firefox → 세부 정보에서 사생활 보호 창에서 실행 을 허용으로 바꾸세요.

  2. 도우미 설치

    파일을 받아 한 번 실행하세요. 관리자 권한은 필요 없습니다. 서명되지 않은 프로그램이라 Windows 가 경고하면 추가 정보 → 실행 을 누르세요.
